    Datos y límites

    Fuente: Mapillary API v4 (CC BY-SA). Zona cubierta: .

    • Los objetos provienen de map_features: detecciones automáticas, no un censo.
    • Las trayectorias se reconstruyen con las marcas de tiempo de esas detecciones y se ajustan a la red vial (OSRM, perfil de automóvil). El modo se infiere solo por la velocidad media (<7, 7–25, >25 km/h) y es poco fiable: .
    • La densidad 3D mide recorrido reconstruido (muestras cada ~40 m de trayectoria), no puntos de detección. No hay datos de edificios: la altura solo codifica el valor.
    • El reloj de 24 h superpone trayectorias de todas las fechas () según la hora del día en que se capturaron: muestra el ciclo diario, no un día concreto.
    • La cobertura depende de quién captura: una campaña concentrada puede dominar un año entero.
