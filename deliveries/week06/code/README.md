# Código de la Semana 6

`make_week06_data.py` genera las tablas de `../data/processed/` a partir de los datos procesados del proyecto
(`../../week12/data/processed/`). Ejecutar desde esta carpeta:

```bash
pip install -r ../../../requirements.txt
python make_week06_data.py
```

El pipeline completo (extracción, limpieza, trayectorias y tablas procesadas) está en [`../../week12/code/`](../../week12/code/) (scripts 01–05).
